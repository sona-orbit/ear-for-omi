# Ear for Omi

Website for **Ear for Omi** — an independent, third-party iPhone app for the Omi pendant. Recordings and data go to a backend you set up yourself; the developer runs no server.

Served by GitHub Pages at https://sona-orbit.github.io/ear-for-omi/

- Home, support and privacy pages in English and 繁體中文
- Static HTML and CSS with a little vanilla JavaScript; no build step on this repository
- Contact: sona.orbit.hi@gmail.com
